# Plix - Decentralized Social Media Platform

Plix is a decentralized social media platform that integrates entertainment APIs, AI-powered features, and Walrus for decentralized storage.

## Key Features

- **Decentralized Data Storage**: Utilize Walrus for secure and censorship-resistant storage of user-generated content.
- **User Profiles**: Create customizable profiles using Sui objects, enabling users to manage their data and preferences.
- **Content Sharing**: Implement content sharing using Sui's transfer functionality and Walrus storage.
- **Entertainment APIs**: Integrate music, movie, and TV show APIs to enhance user engagement.
- **AI-Powered Features**: Leverage AI for content generation, user response, and personalization.
- **Private Messaging**: Develop a secure and private messaging system.

## Technical Requirements

- **Sui Move Smart Contracts**: Write contracts to manage user profiles, content sharing, and platform functionality.
- **Sui Tools**: Utilize Sui CLI, Sui SDK, and Sui Explorer for blockchain interactions.
- **Walrus Integration**: Ensure seamless integration with Walrus for decentralized storage.

## Project Structure
